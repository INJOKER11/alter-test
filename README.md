# ALTER

Готовая mobile-first витрина блогеров. HTML, CSS, TypeScript и Vite. Без React, backend и внешних API. Шрифты Manrope и Cormorant Garamond хранятся локально. Никаких запросов к сторонним сервисам при обычном просмотре страницы.

## Запуск

Нужен Node.js 22.12+ (рекомендуется Node.js 24) и npm.

```sh
npm ci
npm run dev
```

Откройте локальный адрес, который напечатает Vite.

```sh
npm run check   # проверка TypeScript
npm run build   # проверка TypeScript и production-сборка в dist/
npm run preview
```

`npm run build` создаёт готовую версию в `dist/`. Архив исходников для GitHub не содержит `dist/` и `node_modules/`: зависимости устанавливаются через `npm ci`, сборку выполняет Vercel или локальная команда. Для просмотра используйте `npm run dev` или после сборки `npm run preview`; открывать `index.html` через `file://` не следует.

## Telegram — пока не настроен

Единственное место настройки: **`src/config.ts`**.

```ts
export const TELEGRAM_URL = ''; // Вставьте свой HTTPS-адрес t.me
```

Пустой адрес включает сообщение «Ссылка на Telegram пока не добавлена» во всех точках входа. Реальный username не придуман. После указания адреса и повторной сборки все кнопки становятся ссылками, открывающими Telegram в новой вкладке. Адрес проверяется при сборке: допустимы HTTPS-ссылки `t.me` и `telegram.me`.

## Что где менять

```text
src/data/authors.ts   Типизированный массив: авторы, темы, биографии, публикации
src/config.ts         Telegram
src/main.ts           Фильтры, диалоги, фокус, блокировка прокрутки, уведомление
src/styles.css        Базовая mobile-first вёрстка
src/premium.css       Журнальная тема, типографика, состояния и CSS-анимации
src/motion.ts         Появления при прокрутке, переходы фильтров, индикатор чтения
src/fonts.css         Локальные WOFF2: кириллица и латиница
build/render.ts       HTML-шаблоны страницы, карточек и профилей
public/images/        Портреты WebP и отдельные миниатюры для hero
public/fonts/         Шрифты и лицензии SIL OFL
public/favicon.svg    Значок ALTER
index.html            Язык, title, description, базовая HTML-оболочка
vite.config.ts        Подстановка контента в HTML до сборки
dist/                 Готовая статическая сборка
```

Карточки и профили создаются из одного массива. Обновляйте данные, а не HTML в `dist/`. Vite отслеживает модули конфигурации при локальной разработке; production нужно пересобирать.

Для замены демонстрационного автора на своего блогера обновите его имя, никнейм, возраст, тему, описание, биографию, цитату, публикации и `alt` в `src/data/authors.ts`. Замените файл портрета в `public/images/` либо укажите новый путь в `image`, затем выполните `npm run build`. Тексты интерфейса не привязаны к происхождению изображений.

Вместе с основным WebP замените три миниатюры с тем же именем и суффиксами `-96.webp`, `-192.webp`, `-288.webp` (ширина 96, 192 и 288 px, пропорции 3:4). Например, для `/images/max.webp` используются `/images/max-96.webp`, `/images/max-192.webp`, `/images/max-288.webp`. Шаблон формирует `srcset` из пути `image`; миниатюры нужно подготовить до сборки.

## Рендеринг и SEO

Vite подставляет контент во время сборки. Готовый `dist/index.html` содержит имена, описания, биографии и все 12 публикаций — для их получения не требуется запускать JavaScript.

Без JavaScript профили остаются обычными секциями страницы, а ссылки «Смотреть блог» ведут к ним по якорю. С JavaScript те же секции перемещаются в нативные модальные `dialog`; фильтры появляются после подключения скрипта. Так данные не дублируются между HTML и клиентским кодом.

Есть семантические заголовки, `lang="ru"`, title, description и альтернативные описания изображений. Реальный домен не предоставлен, поэтому фиктивный canonical или sitemap не добавлены. После выбора домена можно добавить canonical в `index.html`. Отдельных индексируемых страниц авторов пока нет: это одностраничная витрина. Статическая генерация помогает доступности контента, но не гарантирует его индексацию или позиции в поиске.

## Адаптивность и доступность

- Одна колонка до 600 px, две от 600 px, четыре от 1280 px.
- На телефонах профиль занимает почти весь экран, на больших экранах — центральное окно.
- Кнопки закрытия, Escape, закрытие по фону, удержание фокуса, возврат к исходной ссылке.
- Блокировка фоновой прокрутки с восстановлением позиции; отдельная прокрутка содержимого профиля.
- Skip-link, видимый фокус, `aria-pressed` у фильтров, озвучиваемое уведомление Telegram.
- `prefers-reduced-motion`, заданные размеры и пропорции изображений.
- Если нативный `dialog` не поддерживается, профили сохраняются секциями страницы.

## Визуальный стиль и анимации

- Manrope для интерфейса и Cormorant Garamond для выразительных заголовков и цитат.
- Цитаты на портретах, интерактивные мини-портреты в первом экране на широких экранах и контрастный завершающий блок.
- Закреплена только шапка: сплошной фон, тонкая граница, без тени. Фильтры прокручиваются вместе с каталогом.
- Карточки появляются один раз при входе в область просмотра. Смена фильтра запускает короткий переход; не нужно ждать анимации, чтобы выбрать другую тему.
- Наведение реагирует только на устройствах с поддержкой hover. На сенсорных устройствах действия доступны обычным тапом.
- Профиль плавно открывается и закрывается. Кнопка «Далее» переключает автора внутри окна, сохраняя блокировку фоновой страницы и возврат фокуса на исходную ссылку.
- Движение отключается при `prefers-reduced-motion`, в том числе если настройка меняется во время просмотра. Нет бесконечных анимаций, перехвата прокрутки и заставки перед загрузкой.

Дополнительные библиотеки анимации не используются: CSS, Web Animations API и IntersectionObserver. Шесть файлов WOFF2 суммарно весят около 112 КБ. Лицензии лежат рядом с файлами. Исходники шрифтов: [Google Fonts — Manrope](https://github.com/google/fonts/tree/main/ofl/manrope) и [Cormorant Garamond](https://github.com/google/fonts/tree/main/ofl/cormorantgaramond).

## Портреты

В комплекте оставлены демонстрационные портреты для последующей замены на материалы блогеров. Четыре WebP весят примерно 228–315 КБ каждый, размер 1200 × 1600. Это небольшое увеличение исходного размера 1086 × 1448; дополнительной исходной детализации оно не добавляет.

Полароиды hero используют отдельные миниатюры 96 × 128, 192 × 256 и 288 × 384 (примерно 3–20 КБ на файл). `srcset` и `sizes="69px"` позволяют браузеру выбрать вариант под плотность экрана. Загрузка eager начинается без ожидания прокрутки. Полароиды показываются от 1100 px; подписи не перекрываются соседними карточками. На телефоне цитата профиля занимает всю ширину под портретом и данными автора.

## Ограничения

Telegram ожидает ваш адрес. Контент локальный, обновления требуют пересборки. Имена, портреты и публикации в комплекте — демонстрационное наполнение для замены на ваши материалы. Нет аналитики, CMS, авторизации или интеграции с реальным Telegram API.

Результаты проведённых проверок — в `QA.md`.
